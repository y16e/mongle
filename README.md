# ☁︎ Mongle

내 화면에 몽글몽글 날씨. 브라우저에서 바로 돌아가는 데스크탑 날씨 놀이터예요.

- ❄️ **눈** — 창 위와 Dock에 쌓여요. 창을 끌면 미끄러져 떨어지고, 휙 던지면 날아가요.
- 🍂 **낙엽** — 쌓인 낙엽을 포인터로 쓸어 보세요.
- 🌠 **별똥별** — 창에 부딪히면 불꽃으로 부서져요.
- 🌧️ **비** — 닿는 곳마다 튀고, 가끔 번개가 쳐요.
- 🌸 **벚꽃** — 창 위에서 잠깐 쉬었다 사라져요.
- ✨ **반딧불이** — 포인터를 멈추면 주위로 모여요.

배경화면 14종(새벽·일출·아침·한낮·골든 아워·일몰·해 질 녘·밤·겨울·비·별·반딧불이·가을·봄)은 모두 코드로 그려요. "자동"을 고르면 시간대에 맞춰 바뀌어요.

## 🍎 Mac 앱

진짜 바탕화면 위에서 돌아가는 메뉴 막대 앱이에요. 실제 창 위에 눈이 쌓이고, 창을 끌면 떨어져요.
클릭은 그대로 통과해서 평소처럼 컴퓨터를 쓸 수 있어요.

```bash
./mac/build.sh
cp -R build/Mongle.app /Applications/
open /Applications/Mongle.app
```

메뉴 막대의 ☁︎ 아이콘에서 날씨, 세기, 배경화면을 고르고 "로그인할 때 자동 실행"을 켤 수 있어요.
Xcode Command Line Tools(`xcode-select --install`)가 필요해요. macOS 13 이상.

## 웹 버전 실행

빌드 없이 정적 파일만 있으면 돼요.

```bash
python3 -m http.server 5178
```

그다음 http://localhost:5178 을 여세요.

## 단축키

| 키 | 동작 |
| --- | --- |
| `1`–`6` | 효과 바꾸기 |
| `0` | 일시 정지 |
| `N` | 창 추가 |
| `Esc` | 패널 닫기 |

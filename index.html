어울리는 배경화면.
메뉴에서 한 번 누르면 바탕화면이 바뀌어요.

'자동'으로 두면 새벽부터 밤까지 시간에 맞춰 하늘이 바뀌어요. 모두 코드로 그려서 어떤 해상도에서도 선명해요.

1분이면 끝.
한 줄이면 돼요.

  1. 1

    터미널 열기

    ⌘ Command + Space를 누르고 터미널이라고 입력한 다음 Enter를 누르세요.

  2. 2

    한 줄 붙여 넣기

    아래 명령을 복사해서 터미널에 붙여 넣고 Enter를 누르세요. 내려받고, 응용 프로그램 폴더에 넣고, 실행까지 알아서 해요.

  3. 3

    날씨 고르기

    화면 맨 위 메뉴 막대의 ☁︎ 구름을 눌러 날씨와 배경화면을 고르세요. 눈이 쌓이면 눈놀이에서 빗자루, 제설차, 눈사람을 꺼내 보세요.

curl -fsSL https://y16e.github.io/mongle/install.sh | bash

설치 스크립트가 하는 일이 궁금하면 install.sh에서 전부 볼 수 있어요.

터미널이 낯설다면: 직접 내려받아 설치하기
  1. Mongle-mac.zip을 내려받아 열고, 나온 Mongle을 응용 프로그램 폴더로 끌어다 놓으세요.
  2. Mongle을 열면 "Apple이 악성 코드가 없음을 확인할 수 없습니다"라는 창이 떠요. 당황하지 말고 완료를 누르세요.
  3. 시스템 설정 → 개인정보 보호 및 보안을 열고 맨 아래로 내리세요. "Mongle이(가) 차단되었습니다" 옆의 그래도 열기를 누르세요.
  4. Mac 암호를 넣고, 한 번 더 그래도 열기를 누르면 끝이에요. 다음부터는 그냥 열려요.

왜 이런 창이 뜨나요? Mongle은 Apple의 유료 개발자 공증을 아직 받지 않은 무료 앱이라서, macOS가 처음 한 번 확인을 받아요. 코드는 GitHub에 모두 공개되어 있어요.

좋은 것들.

정말 무료예요?

네, 전부 무료예요. 구독도 광고도 없어요. 코드도 GitHub에 공개되어 있어요.

클릭이 막히지 않나요?

날씨는 투명한 막 위에 그려지고, 클릭은 그대로 아래로 통과해요. 눈놀이 도구를 들고 있는 동안만 마우스가 눈놀이에 쓰이고, ✓ 다 놀았어요나 Esc를 누르면 원래대로 돌아와요.

Mac이 느려지나요?

가볍게 만들었어요. 그래도 신경 쓰이면 메뉴에서 세기를 '살살'로 낮추거나 '일시 정지'를 고르세요.

"악성 코드가 없음을 확인할 수 없습니다" / "손상되었습니다"라고 나와요.

공증을 받지 않은 앱을 브라우저로 내려받으면 나오는 안내예요. 설치 방법의 한 줄 명령으로 설치하면 이 창 없이 바로 열려요. 이미 내려받았다면 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기를 누르세요.

원래 배경화면으로 돌아갈 수 있나요?

그럼요. 메뉴 → 배경화면 → 원래 배경화면으로 되돌리기를 누르면 처음 쓰던 배경화면으로 돌아가요.

컴퓨터를 켤 때 자동으로 켜지게 할 수 있나요?

메뉴에서 로그인할 때 자동 실행을 켜 두세요.

모니터가 여러 대예요.

지금은 메뉴 막대가 있는 메인 화면에 날씨가 내려요. 배경화면은 모든 화면에 바뀌어요.

Windows에서도 되나요?

아직은 Mac만 지원해요. Windows나 휴대폰에서는 브라우저 버전으로 즐겨 주세요.
